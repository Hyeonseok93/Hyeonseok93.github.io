# 공통 원칙

개발자가 제공하는 서비스는 다음 원칙을 따릅니다.

| 항목 | 내용 |
| --- | --- |
| **수집 최소화** | 서비스 제공에 필요한 범위에서만 데이터를 처리합니다. |
| **로컬 저장** | 별도 안내가 없는 한 데이터는 사용자 기기·브라우저 내부에만 저장합니다. |
| **서버 미전송** | 사용자 데이터를 개발자 서버로 전송하지 않습니다. |
| **제3자 미판매** | 사용자 데이터를 판매하거나 광고 목적으로 제3자에게 제공하지 않습니다. |
| **계정 없음** | 별도 회원가입·로그인을 요구하지 않습니다. |

개발자가 **의도적으로 수집하지 않는** 정보 예시는 다음과 같습니다.

- 이름, 주소, 이메일, 전화번호 등 **개인 식별 정보**
- 위치(GPS), IP 주소를 식별 목적으로 저장하는 행위
- 금융·결제·신용 관련 정보
- 이메일·채팅 등 **개인 커뮤니케이션** 내용
- 방문한 웹페이지 **전체 목록(웹 기록)** 의 서버 저장

# 서비스별 상세

## Short Alert {#short-alert}

**Short Alert**는 YouTube Shorts 및 Instagram 숏폼(릴스·스토리 등)의 시청 시간을 측정하고, 사용자가 설정한 연속·누적 한도에 도달하면 경고 알림과 잠금 화면을 표시하는 **Chrome 확장 프로그램**입니다.

📦 **GitHub:** [MINI_ShortsAlert](https://github.com/Hyeonseok93/MINI_ShortsAlert)

### 처리하는 데이터

| 데이터 | 용도 | 저장 위치 |
| --- | --- | --- |
| 연속·누적 시청 시간 | 타이머 표시, 경고·잠금 판단 | `chrome.storage.local` (브라우저 로컬) |
| 사용자 설정 (한도, 알림 on/off, 잠금 해제 문장 등) | 확장 기능 설정 유지 | `chrome.storage.local` |
| 날짜별 시청 기록 (최대 90일) | 기록 목록·차트 표시 | `chrome.storage.local` |
| 위젯 접기/펼치기 상태 | UI 상태 유지 | `chrome.storage.local` |
| 활성 탭 URL (YouTube/Instagram) | 숏폼 페이지 여부·메시지 동기화 | 처리 시에만 사용, 서버 저장 없음 |

### 사용 권한

| 권한 | 사용 목적 |
| --- | --- |
| `storage` | 설정·시청 기록을 브라우저 로컬에 저장 |
| `tabs` | 활성 탭이 지원 사이트인지 확인하고 content script와 통신 |
| `alarms` | 백그라운드 타이머 유지 |
| `youtube.com` / `instagram.com` | 숏폼 페이지에서 재생 감지, 위젯·알림·잠금 UI 표시 |

### 하지 않는 것

- YouTube·Instagram **계정 정보** 수집
- 시청한 **영상 제목·댓글·게시물 내용** 수집
- 데이터의 **외부 서버 전송·판매·광고 활용**
- **원격 코드** 실행 (패키지에 포함된 로컬 파일만 실행)

### 데이터 삭제

- 확장 프로그램 내 **초기화** 기능으로 설정·기록을 삭제할 수 있습니다.
- Chrome에서 확장 프로그램을 **제거**하면 해당 브라우저의 로컬 저장 데이터도 함께 삭제됩니다.
